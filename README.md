# mini-message-board

A simple message board built using Node.js, Express, and EJS, where users can post messages and view them in a list.

🚀 Live Demo

📌 Features
-View messages on the homepage
-Submit new messages with a username and text
-Messages are timestamped
-View individual messages detail pages

🛠️ Tech Stack
-Node.js
-Express.js
-EJS templating engine

💻 Run It Locally
git clone https://github.com/mlanda98/mini-message-board.git
cd mini-message-board
npm install
npm start
Open your browser to http://localhost:8080
